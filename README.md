Server02

Десктопное приложение с веб-интерфейсом для управления сервером и архивом.

1)Быстрый запуск (для пользователей)

Для запуска готового приложения не требуется установка Python:

Перейдите в папку dist/.

Найдите и запустите файл gui.exe.

2)Структура проекта

gui.py — Главная точка входа для запуска графического интерфейса приложения.

app.py — Основная логика работы приложения и серверная часть.

templates/ — Шаблоны интерфейса (HTML + CSS):

index.html — Главная страница приложения.

archive.html — Страница архива.

dist/ — Скомпилированная версия приложения, готовая к запуску (gui.exe).
